## 2. Game Overview

This project is a Slot Machine game developed using Unity. It provides a simple slot machine experience where players can interact with the machine and try their luck at getting matching symbols.

The repository includes the Unity source project and a browser-compatible Web build.

## 3. Instructions to Run the Web Build

The Web build is available in the `Build` folder.

**To run the game locally:**

1. Clone or download this repository.
2. Make sure Python is installed.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python -m http.server 8000 --directory Build
   ```

5. Open your browser and visit:

   `http://localhost:8000`

6. The game should load in your browser.

**Note:** Run the Web build through a local web server instead of opening `index.html` directly.
